# FBO Baru

Repositori rilis untuk aplikasi **FBO Baru** (Film Box Office Baru).
Aplikasi ini merupakan kloning dari CloudStreamXR dengan kustomisasi logo dan nama.

## Tautan Penting
- **Pembaruan Aplikasi (OTA):** `https://raw.githubusercontent.com/xr3ed/FBO-Baru/main/update.json`

## Catatan
- File APK rilis dapat diunduh dari tab **Releases**.
- Ikon utama disimpan di folder `icon`.
